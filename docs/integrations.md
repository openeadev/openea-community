# Integrations

OpenEA Community 1.0 focuses on manual entry, CSV import/export, and the versioned REST API. ServiceNow, AWS, Azure, GitHub, Terraform, Jira, OIDC, SAML, LDAP, discovery connectors, candidate changes, and field-level provenance workflows are post-MVP roadmap items.

External systems should provide evidence while OpenEA Community retains architectural meaning. Future connectors should normalize external data into governed candidate changes rather than automatically converting every infrastructure resource into an enterprise architecture object.
